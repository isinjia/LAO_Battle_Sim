# 원문 조건 복원 후 재시험을 위한 확인표

이번 요청에서는 원문 조건을 복원하기 위한 자료의 존재 여부를 조사했다. 새로운 전투 실행 결과는 만들지 않았다.

## 검증 기준 정정

앞선 시험은 제목에서 추출한 편성에 통일된 육성·대표 장비·자동 배치를 적용한 예비 시험이다. 해당 성공 비율을 원문 공략 유지율이나 개편 전후 호환률로 사용하면 안 된다. 원문의 장비·배치·육성을 맞춘 뒤 같은 난수 조건으로 재시험해야 한다.

## 확보한 자료

- 실패·결과 변동·확인 보류가 있는 공략 글: 944건.
- 해당 전투 구역별 시험 항목: 992건.
- 그중 저장된 본문이 있는 공략: 282건.
- 본문에 육성·장비·배치 등의 조건 문구가 있는 공략: 223건.
- 클로드 기록에서 복구한 기존 공략 화면: 두 장.
- 장비·배치·육성 조건을 모두 확인해 완전 복원을 확정한 항목: 아직 없음.

## 원문 입력이 확보됐을 때의 재시험 절차

1. 공략별 장비 이름·등급·강화 수준과 아홉 칸 배치를 기록한다.
2. 레벨·승급·기술 수준·연결·선택 보너스·호감도·서약·시작 체력·강화 점수를 확인한다.
3. 원문이 명시한 기술 우선순위와 수동 이동·대기 지시를 반영한다.
4. 원문의 표시 능력치와 재현한 전투원 능력치를 대조한다.
5. 확인하지 못한 값이 있으면 완전 복원으로 표시하지 않는다. 범위가 명시된 조건은 원문과 동일한 수치 복원과 구분한다.
6. 동일한 편성으로 기존 예비 시험과 원문 조건 복원 시험을 실행해 결과를 비교한다.
7. 승패·안정성·행동 수·교착 진입 지점을 나눠 기록한다. 원문의 구형 전투와 직접 비교하지 못한 경우 그 한계를 유지한다.

## 현재 필요한 자료

장비·배치·육성이 담긴 원문 화면이나 저장한 원문 자료의 위치가 필요하다. 원문 사이트는 브라우저 보안 정책으로 접근이 차단됐다. 차단된 접근을 우회하지 않고, 기존에 보관된 파일이나 사용자가 제공하는 원문 자료를 기준으로 복원을 진행해야 한다.
