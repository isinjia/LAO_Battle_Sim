# 기존 능력치와 수동 분배 유지 조건의 전투 검증 상세 보고서

시험일: 2026년 10월 22일  |  대상: 기존 공략 조합의 개편 전투 활용 가능성

## 1. 검토 결론과 판단 범위

기존 성장표와 수동 능력치 분배를 유지한 상태에서도 기존 공략 조합 상당수가 개편 전투에서 클리어되는 것을 확인했다. 다만 이번 시험만으로 기존 공략 전체의 동작·반복 안정성·소요 시간이 그대로 유지된다고 결론 내릴 수는 없다.

추천 수동 분배에서는 유효 시험 2,770건 중 2,113건(76.3%)이 한 번 이상 성공했고, 1,778건(64.2%)이 세 번 모두 성공했다. 다섯 명 편성은 세 번 모두 성공한 비율이 87.2%였지만, 한 명 편성은 50.9%였다. 적은 인원으로 반복 파밍하는 공략의 정밀 재현을 우선할 근거가 된다.

이 수치는 공략 제목에서 추출한 편성에 시험용 육성·장비·배치를 적용한 결과다. 원문 공략 조건을 완전히 복원한 호환성 시험이나, 개편 전 전투 엔진과 개편 후 전투 엔진을 같은 조건으로 비교한 시험은 아니다. 이전 대화에서 자동 성장 조건을 섞어 산출한 기존 조합 유지율은 이번 결론의 근거에서 제외한다.

| 판단 항목 | 이번에 확인한 내용 | 아직 확인하지 못한 내용 |
|---|---|---|
| 기존 편성 활용 | 수집한 전투원 조합을 개편 전투에서 실행해 승패 기록 확보 | 모든 원문 공략이 그대로 작동하는지 |
| 수동 능력치 유지 | 기존 성장표와 수동 강화 점수 반영 | 최종 반영될 실제 게임 화면·서버의 능력치 일치 |
| 반복 안정성 | 서로 다른 난수 시작값 세 개에서 성공 횟수 확인 | 장시간 반복 파밍의 실패율 |
| 전투 흐름 | 본 행동·추가 행동·누적 행동 수 기록 | 개편 전후 실제 조작감·연출 시간·실제 분당 파밍량 |

입력 자료 2,778건은 모두 공략 제목에서 전투원을 추출한 항목이었다. 원문 편성 이미지에서 배치를 직접 복원한 입력은 이번 전체 시험 자료에 없었다. 전투원 이름이 해석된 공략만 선정했으므로, 게임 전체 공략이나 전체 전투 구역을 대표하는 무작위 표본도 아니다.

## 3. 능력치 복원과 두 비교 조건

두 조건 모두 전투 규칙·기술·적·전투 구역 자료는 개편 상태를 사용하고, 전투원의 기본 성장표와 수동 능력치 분배를 기존 방식으로 재현했다. 능력치 자동 성장 조건은 이번 비교에 포함하지 않았다.

| 항목 | 기본 수동 분배 | 추천 수동 분배 |
|---|---|---|
| 성장표 | 기존 성장표 | 기존 성장표 |
| 적중·회피·치명의 레벨 성장 | 기존 방식대로 추가 자동 성장 없음 | 기존 방식대로 추가 자동 성장 없음 |
| 수동 강화 점수 | 100레벨 기준 297점 | 100레벨 기준 최대 297점 |

| 분배 근거 | 단순화한 비교용 규칙 | 수집 공략의 전투원별 목표치, 자료 부족 시 역할별 기준 |

추천 분배에 쓰인 206명 중 97명은 커뮤니티 자료 기반이고, 109명은 자료가 부족해 역할별 기준을 사용했다. 추천 분배라는 이름이 각 공략의 원문 분배를 그대로 읽어 넣었다는 뜻은 아니다. 공략마다 다른 장비·지원 효과·상대 회피에 따라 최적 분배는 달라질 수 있다.

수동 강화 점수의 합계가 297점을 넘지 않고, 회피와 치명에 각각 100점을 초과해 분배하지 않았는지 확인했다. 기존과 현재 성장표의 다른 항목도 비교했고, 기존 비교 도구가 포츈의 기본 화염·냉기·전기 저항 35%를 복원하지 않는 점을 보완했다. 포츈이 포함된 네 항목은 두 조건에서 다시 실행해 최종 기록에 반영했다.

## 4. 공통 육성·장비·배치 조건

| 항목 | 실제 시험 조건 | 해석상 주의점 |
|---|---|---|
| 레벨 | 전원 100 | 105~120레벨을 요구하는 원문 공략과 차이 가능 |
| 승급 | 전투원별 최대 승급 | 원문의 저등급 편성과 기술 구성이 다를 수 있음 |
| 기술 수준 | 10 | 원문 기술 수준과 다를 수 있음 |
| 코어 연결 | 없음 | 연결 보너스와 완전 연결 선택 효과 미반영 |

| 배치 | 역할·사거리 기준의 저장된 자동 배치 | 원문의 특정 칸을 전제로 한 보호·지원·회피 공략과 차이 가능 |
| 조작 | 자동 전투 | 수동 기술 선택·이동이 필요한 공략은 재현 부족 |

제목에 105~120레벨을 명시한 항목이 28건 있었지만 입력 전투원에는 개별 레벨이 지정돼 있지 않아 모두 100레벨로 실행됐다. 반대로 무연결을 명시한 항목은 397건이지만, 실제 시험은 원문 표기와 무관하게 모든 항목에 연결 보너스를 주지 않았다. 특히 연결을 요구하는 공략의 실패를 전투 개편 탓으로 단정할 수 없는 이유다.

장비는 공격·치명·적중·행동력 등의 수치를 기준으로 자동 선택했다. 수치 없이 보조 효과만 주는 장비의 가치는 이 선택 규칙으로 충분히 평가하지 못한다. 원문 장비를 맞추지 않은 상태에서 분배만 바꾸는 시험이라는 한계를 함께 봐야 한다.

## 5. 집계 기준

| 지표 | 정의 |
|---|---|
| 한 번 이상 성공 | 세 실행 중 승리 기록이 하나 이상 존재 |
| 세 번 모두 성공 | 서로 다른 난수 시작값 세 개에서 모두 승리 |
| 한두 번만 성공 | 세 실행의 판정이 끝났으며 승리가 한 번 또는 두 번 |
| 성공 없음, 실행 완료 | 승리가 없고 계산 시간 제한 없이 세 실행의 판정이 끝남 |
| 확인 보류 | 계산 시간 제한 등으로 한 번 이상 실행이 미완료 |
| 집계 제외 | 적 편성이 없어 전투 자체가 없는 이야기 구역 |

한 번 이상 성공은 세 번 모두 성공을 포함하는 지표이므로 둘을 더하면 안 된다. 확인 보류 항목의 승리 횟수가 0이더라도 확정 실패로 분류하지 않았다. 전체 비율은 전투가 없는 8건을 제외한 2,770건을 분모로 하며, 확인 보류 항목은 분모에 남겨 성공률을 부풀리지 않았다.

서로 다른 난수 시작값 세 개의 실행은 초기 재현성을 살피는 최소 확인이다. 세 번 모두 성공을 장기 파밍의 무실패 보증이나 통계적으로 확정된 안정성으로 해석해서는 안 된다.

모의실험의 중단 기준에 쓰는 전체 실행 행동 수와, 뒤의 제한 임무 분석에 쓰는 본 행동 수는 구분한다. 추가 행동을 포함해 실행 제한에 도달했다고 해서 임무 판정용 행동 수도 같은 값이라는 뜻은 아니다.

## 8. 수동 분배를 바꿨을 때의 변화

두 조건에서 판정이 끝난 2,768건을 짝지어 비교했다. 기본 분배에서 성공이 없었지만 추천 분배에서는 성공한 항목이 68건이고, 반대로 기본 분배에서 성공했지만 추천 분배에서는 성공이 없는 항목이 30건이었다. 추천 분배로 세 번 모두 성공한 항목은 전체 기준으로 60건 늘었다.

## 9. 실패·교착·확인 보류 분석

### 행동 수 제한과 교착 정황

기본 분배는 359회, 추천 분배는 352회가 모의실험의 실행 행동 2,000회 제한에 도달했다. 그중 오랫동안 양쪽 체력 변화가 없었다는 교착 진단 기록은 각각 301회와 294회다. 진행 멈춤 판정이 0회라는 사실을 전투가 끝나지 않는 상황도 없었다는 의미로 읽어서는 안 된다.

이 결과만으로 원인을 하나로 확정할 수는 없다. 사거리 밖 배치, 적중 부족, 필요한 특수 장비 누락, 이동 규칙, 행동 불가 효과의 해제 시점 등을 원문 조건과 함께 확인해야 한다. 체력 변화가 없었다는 기록은 재현 우선순위를 정할 근거이며, 곧바로 특정 원인을 입증하는 자료는 아니다.

### 30회 제한 임무의 가정별 대조

## 13. 개발자 노트에 사용할 수 있는 표현

확인한 사실에 맞는 표현은 “기존 성장 방식과 수동 능력치 분배를 유지한 조건으로 기존 공략 조합을 시험했고, 상당수 조합이 개편 전투에서도 클리어되는 것을 확인했다”는 수준이다. “모든 기존 공략을 그대로 사용할 수 있다”, “전투 시간과 파밍 효율이 유지된다”, “교착 문제가 없다”는 표현을 뒷받침할 자료는 아직 없다.

아래 문장은 개발자 노트에 넣을 수 있는 초안이다.

> 사령관님들께서 키워두신 전투원과 직접 맞춰두신 능력치를 다시 손봐야 하는 건 아닌지 걱정하실 것 같습니다. 이번에는 기존 성장 방식과 수동 능력치 분배를 유지한 상태에서, 그동안 사용하시던 공략 조합들을 바뀐 전투로 돌려봤습니다. 상당수 조합은 그대로 전투를 마칠 수 있었지만, 이 결과만 보고 모든 공략을 똑같이 쓰실 수 있다고 말씀드리기는 어렵습니다. 특히 적은 인원으로 반복 파밍하는 조합은 장비나 칸 하나에도 결과가 달라질 수 있어서, 공략에 적힌 조건을 맞춰 다시 살펴봐야 할 부분이 남아 있습니다.
