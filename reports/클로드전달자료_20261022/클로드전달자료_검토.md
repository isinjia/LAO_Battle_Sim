# 클로드 전달 자료 검토

## 확인한 성과

- 압축 파일에는 개발자 노트 초안, 도쿠위키 상세 보고서, 공략별 근거 자료 표가 들어 있다.
- 같은 작업 폴더에 실제 시험 도구·입력·실행 기록도 남아 있어 보고서의 주요 합계를 독립적으로 다시 집계했다.
- 58개 항목의 두 조건이 각각 같은 난수 시작값 열 개를 사용했고, 조건별 580개 실행 기록이 존재한다.
- 보고된 승리 110회에서 253회, 열 번 모두 승리한 항목 0건에서 15건은 저장된 실행 기록의 합계와 일치한다.
- 원문 값 일부 반영과 배치 후보 탐색을 구분한 기록이 있고, 완전 복원 항목은 0건이라고 명시돼 있다.

## 수정 또는 재확인이 필요한 부분

### 낮은 레벨에 남아 있는 예비 강화 점수

- 엄격 원문 조건 중 네 시험 항목에서 레벨은 90으로 바뀌었지만 수동 강화 점수 합계는 예비 조건의 297점으로 남았다.
- 보고서 자체의 레벨당 3점 기준으로는 90레벨 총점이 270점이므로, 각각 27점이 초과한다.
- 영향 항목은 기다림의 시간, 망가진 육체, 마음 깊은 곳의 병, 그녀를 꼼짝 못하게 하는 방법의 해당 공략이다. 같은 항목의 여러 전투원에 걸쳐 여섯 명분 입력이 해당한다.
- 따라서 58개 항목 전체의 개선 수치를 공개 문구에 바로 인용하기 전에 점수를 합법적인 총량으로 맞추고 영향 항목을 재시험해야 한다. 임의의 점수 삭감을 원문 분배 복원으로 표시해서는 안 된다.

### 시작 체력 입력 전달 누락

- 시험 도구는 시작 체력 비율을 원문 입력에서 읽도록 돼 있지만, 전투원 사양을 만드는 단계에서 해당 값을 전투 실행 사양으로 옮기지 않는다.
- 실제로 값이 있는 입력은 해석 포함 조건 한 건이며, 주요 엄격 조건 58건의 합계에는 직접 해당하지 않는다.
- 중파 조건 검증을 완료했다고 설명하려면 이 전달 경로를 수정하고 해당 입력을 재실행해야 한다.

### 개발자 노트 초안의 표현

- 초안의 걱정 중심 도입부는 사용자가 삭제를 요청한 내용이므로 사용하지 않는다.
- 원문 조건을 그대로 맞췄다는 제목과 표현은 완전 복원 0건이라는 보고서와 맞지 않는다. 원문에서 확인한 조건을 부분 반영했다고 표현해야 한다.
- 티아멧의 앞줄 배치 성공은 원문 배치를 확인한 결과가 아닌 후보 탐색 결과다.
- 적중·회피를 이용해 장비를 역산한 뒤 같은 적중·회피가 일치한 것을 독립 검증으로 세지 않는다.
- 다수 공략의 캡처를 사용자에게 다시 요청하는 마무리는 삭제한다.

## 개발자 노트에 반영할 수 있는 범위

- 기존 성장 방식과 수동 분배 유지, 신규 유저용 선택형 자동 분배 제공이라는 확정 방향은 유지한다.
- 전투 흐름 변경을 설명하는 데 초점을 둔다.
- 원문에서 확인한 육성·장비·배치·기술 사용 조건을 반영하는 검증을 진행했고, 시험 조건에 따라 결과가 달라지는 사례가 있다는 정도로 설명할 수 있다.
- 전체 공략 유지율, 개편 전후 성능 유지, 파밍 시간 개선을 주장하지 않는다.
- 58건 전체의 수치는 입력 수정 후 재시험 전까지 공개용 초안에서 보류한다.

## 기록 해석

이번 검토는 저장된 실행 기록의 독립 집계와 입력·도구 코드 점검이다. 이 검토에서 전투를 다시 실행한 것은 아니다. 총점 초과 네 항목을 제외한 54건의 참고 집계는 별도 자료에 남겼으며, 이 수치 역시 부분 복원된 표본의 결과다.
